## 一位垃圾佬的历程

一切始于一台超级古董机，Geforce GT630，初代 Core 处理器。那时候对电脑的唯一要求就是能开机，能玩4399，能下载 PVZ。  

那是我的第一个“大作”。为了让它跑起来，我第一次知道了什么叫“下载”，什么叫“安装目录”，什么叫“配置要求”。

为了玩上MC，我开始捣鼓启动器，下载 JDK，配置 Java 环境。对于一个还在上小学的孩子来说，那简直像在破解什么密码。但就是在这个过程中，我第一次真正意识到电脑不只是工具，它是一个可以拆解、理解、改造的世界。

从那时起，我对“配置”产生了兴趣。

不是对“顶级配置”的仰望，而是对“每一块钱能买到什么性能”的执念。

后来，我开始真正装机。

CPU 换过 i3 10100、i3 12100F、R7 1700X、R5 5500、R5 5600、R5 5600X、R7 7700...

GPU 换过 RX 570、580、GTX 960、970、1050、1060（3G/6G）、1070、RTX 2060S、RX 5600XT、5700XT、6650XT、6750XT、RTX 4060...

几乎每一代“甜品卡”和“性价比神U”我都摸过、装过、测过、卖过、再换过。
  
主板永远是“丐板”，硬盘是“丐盘”，内存是“丐条”——但电源，从来不敢丐。  

我为数不多坚持的原则是再省不能省电源，炸了全没了。

我折腾过无数个轮回，为了省几十块钱买了二手电源，结果整机不稳，最后还得换新；

为了压住一块显卡，研究风道、换硅脂、加机箱风扇；

为了搞清楚一张矿卡到底能不能用，拆散热、看显存、跑压力测试；

为了一个极致性价比配置单，在某鱼某宝之间反复横跳，蹲到半夜。

有时候装完一台机器，点亮那一刻，比玩游戏还爽。 
 
有时候折腾一整天，最后发现只是内存没插紧。

但就是这些坑，让我从一个“会装机的”变成了一个“懂装机的”。

有人说垃圾佬是“穷折腾”，但我觉得不是。  

我们不是买不起更好的，而是享受那种用有限预算拼出无限可能的成就感。

每一张显卡、每一块CPU、每一个丐板，都有它的性格和故事。  

我们不是在堆配置，是在和硬件对话。

这条路，我走得越远，越不想回头。
